Analizador de errores sintácticos

Escribe o carga tu código fuente. El analizador revisa su estructura, señala cada error con su línea y columna, explica qué esperaba encontrar y, si todo es correcto, dibuja el árbol de sintaxis.

Código fuente

Gramática que reconoce el analizador
programa    → instrucción*
instrucción → bloque | declaración «;» | asignación «;»
            | «if» «(» expr «)» instr [«else» instr]
            | «while» «(» expr «)» instr
            | «for» «(» (decl|asig) «;» expr «;» asig «)» instr
            | «print» «(» args «)» «;» | «return» [expr] «;» | llamada «;»
bloque      → «{» instrucción* «}»
declaración → (int|float|string|bool|var|let) ID [«=» expr]
asignación  → ID «=» expr
expr        → || · && · == != · < > <= >= · + - · * / % · unario(! -) · primario
primario    → NUM | CADENA | true | false | ID | ID«(»args«)» | «(» expr «)»
